# Grizzly Gear Sales Report

A simple Python program for BMIS 365 that reads store sales from `sales.csv` and prints total revenue and revenue by region.

## How to run

```
python report.py
```

On a Mac, you may need `python3 report.py`.

## Files

- `report.py` – the program
- `sales.csv` – the sales data (date, region, product, units, price)
